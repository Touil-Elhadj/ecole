# برنامج تسيير مدرسة الدروس الخصوصية

برنامج سطح مكتب (Windows 10) بالعربية لتسيير مدرسة دروس خصوصية: الأساتذة، الأفواج،
التلاميذ، المدفوعات، الحضور، وحساب نصيب الأكاديمية والأستاذ.

**التقنيات:** Python + PySide6 (Qt) + SQLite. يعمل على حاسوب واحد دون إنترنت.

## القواعد المالية المطبّقة

| القاعدة | التطبيق في البرنامج |
|---|---|
| سعر الحصة 500 دج، والباقة 4 حصص بـ 2000 دج | قابلة للتعديل من الإعدادات |
| الباقة صالحة لأي فوج أو مادة | لكل تلميذ **رصيد حصص** واحد مشترك |
| الغائب لا يُخصم منه | الخصم يتم **عند الحضور فقط** |
| يُسمح بالحضور دون رصيد | يصبح الرصيد سالباً (دَين) ويظهر في قائمة المدينين |
| الأكاديمية تأخذ الثلث | كل حضور = 500 دج تُقسم: الثلث للأكاديمية والباقي للأستاذ |

- الدخل يُحسب **عند الحضور** لا عند الدفع. المال المدفوع مسبقاً ولم يُستهلك يظهر في
  التقارير كـ«أمانة» وليس كربح.
- التقسيم يتم على **المجموع الشهري** لكل أستاذ لتفادي أخطاء التقريب
  (مثال: 3 حضور = 1500 دج ← 500 للأكاديمية و1000 للأستاذ).
- سعر الحصة يُحفظ مع كل حضور، فتغيير السعر لاحقاً لا يغيّر الحسابات القديمة.
- الدفعات **لا تُحذف**: الدفعة الخاطئة تُلغى (من طرف المدير) مع ذكر السبب.

## الشاشات

- **لوحة اليوم:** المقبوض اليوم، الحضور، نصيب الأكاديمية، المدينون، حصص اليوم.
- **التلاميذ والدفع:** بحث سريع، الرصيد بالألوان، الدفع وطباعة الوصل، كشف حساب التلميذ.
- **الحضور:** اختيار الفوج والتاريخ ← تأشير الحاضرين ← حفظ. مع إضافة تلميذ من خارج الفوج
  والدفع مباشرة من نفس الشاشة.
- **سجل المدفوعات:** إعادة طباعة الوصل، إلغاء دفعة، طباعة السجل.
- **الأفواج والأساتذة.**
- **التقارير (للمدير):** كشف الأساتذة الشهري وتسجيل دفع مستحقاتهم، ملخص الأكاديمية،
  قائمة المدينين.
- **الإعدادات (للمدير):** معلومات الأكاديمية، الأسعار والنسبة، المستويات والمواد،
  المستخدمون، النسخ الاحتياطي، سجل العمليات.

## الطباعة

عند كل دفعة يسأل البرنامج: **طابعة وصولات (80 ملم)** أو **طابعة عادية A4** أو بدون طباعة.
التقارير والكشوف تُطبع على A4 مع معاينة قبل الطباعة (ويمكن الحفظ كـ PDF من نافذة الطباعة).

## المستخدمون

- أول دخول: اسم المستخدم `admin` وكلمة السر `admin`، ويطلب البرنامج تغييرها مباشرة.
- **مدير:** كل الصلاحيات.
- **موظف استقبال:** التلاميذ، الدفع، الحضور، الأفواج، الأساتذة (دون التقارير والإعدادات
  وإلغاء الدفعات).

## البيانات والنسخ الاحتياطي

- قاعدة البيانات: `Documents\EcoleData\ecole.db`
- عند كل إغلاق للبرنامج تُحفظ نسخة احتياطية تلقائياً في `Documents\EcoleData\backups`
  (يُحتفظ بآخر 30 نسخة).
- **ننصح بشدة** بتحديد مجلد إضافي من الإعدادات ← النسخ الاحتياطي (فلاشة USB أو مجلد
  Google Drive) حتى لا تضيع البيانات إذا تعطّل الحاسوب.
- الاسترجاع من نفس الشاشة (تُحفظ نسخة من البيانات الحالية قبل الاسترجاع).

## التثبيت على Windows 10

1. ثبّت **Python 3.11 أو أحدث** من [python.org](https://www.python.org/downloads/windows/)
   مع تأشير خيار **Add Python to PATH**.
2. حمّل هذا المجلد على الحاسوب.
3. للتجربة مباشرة: انقر مرتين على `run.bat`.
4. لبناء برنامج تنفيذي (`.exe`): انقر مرتين على `build.bat`، فيظهر البرنامج في
   `dist\Ecole\Ecole.exe`. انسخ المجلد `dist\Ecole` كاملاً إلى أي مكان وأنشئ اختصاراً
   لـ `Ecole.exe` على سطح المكتب. (لا حاجة لـ Python على الحاسوب الذي يشغّل الـ exe.)

## للمطوّرين

```
main.py                  نقطة التشغيل (تسجيل الدخول، النسخ عند الإغلاق، الاسترجاع)
ecole/db.py              الجداول والإعدادات الافتراضية
ecole/services.py        كل منطق العمل والحسابات (مستقل عن الواجهة)
ecole/backup.py          النسخ الاحتياطي والاسترجاع
ecole/printing.py        الوصولات والتقارير (A4 و 80 ملم)
ecole/ui/                الشاشات
tests/                   اختبارات منطق العمل
```

```
pip install -r requirements-dev.txt
python -m pytest -q
python main.py
```

متغير البيئة `ECOLE_DATA_DIR` يغيّر مكان البيانات (مفيد للتجربة).
